共九页、236 道习题，按原书顺序完整保留题号。正文为中文伴读，静态 MathML 公式、内嵌 SVG 图、宽屏左侧目录与窄屏折叠目录；习题先中文题干再展开解答，题干矛盾单列校注。

序言保留原书四段完整英文与逐段中文译文，说明写作目标、版本沿革、六章顺序以及返回周期法和耦合证明的区别。全书地图与各章目录均可进入序言。各章及附录有“定义与定理”索引，正式陈述放在相应小节，可直接按原书编号跳转。

六章与附录共 150 条正式陈述，包括原书全部 115 条编号定理及引理、两条编号定义，以及其他基础定义、模型假设和未编号公式。共 26 条定义、八条未编号公式与推导，附录 A.1 完整写出概率的三条公理，各章链接回共同基础。编号结果均有英文原文、完整中文条件与结论、推导要点、原书页码及正文详细推导链接。页面共有 146 处英文原文块，其中四处是序言完整段落；其他摘录覆盖编号结果和关键定义。原文措辞、中文陈述和伴读注解分别标明。

定理核对保留原书编号，并说明原文的默认条件、边界或笔误，例如第一章重复的收敛定理编号、第三章服务开始链的返回时间与真实时间分布的区别、第五章负漂移的符号和一般函数的到达时间上界、第六章美式支付不提前行权的利率条件。来源目录、逐条陈述与校注见 [statements_review.json](statements_review.json)。

九页全部 66 个小节另有 132 条阅读注解，补充模型理解、公式含义、定理条件、额外推导和解题验算。1440px 及以上采用左目录、正文、右注解的三栏布局，注解随当前小节切换；较窄页面与手机把同一组注解放在对应小节末尾，可点击折叠。关闭 JavaScript 时注解仍能直接阅读。正文原有的详细证明、示例和236道解答保持在原位置。注解内容、位置及历次响应式验收见 [annotations_review.json](annotations_review.json)。

全面复核逐题对照六章全部习题，修正 16 处题干条件、小问或校注，并将 236 道解答扩写为 1,028 个编号步骤。解答标题统一为“解答”，步骤展示代入、积分、消元、矩阵验算、停时条件及期权各节点的支付和持仓。逐章、逐题记录见 [review_manifest.json](review_manifest.json)。

正文与附录覆盖原书 162 个正常编号示例，加入 59 组推导：从模型得到转移矩阵，求解平稳与退出方程，证明计数、更新与停止公式，计算排队指标和完整期权树，并展开 Black–Scholes 积分、Delta 与换极限定理。已有证明与新增推导按小节合并，保留来源、条件与校注。可读文字、公式和程序数值字面量此前修正 524 处，本次另修正 30 处 TeX 命令后省略前导零的公式小数。示例页码、推导位置、关键修订和确切算术复核见 [readability_review.json](readability_review.json)。

例如正文例 2.14 顾客人数方差应为 60、标准差为 √60；例 2.12 同率竞赛概率应为 65/256；例 4.21 三位学生全部离开的均值为 73/60 小时。期权例 6.2 的 HH 持股应为 −1/3；例 6.4 分别处理文字初价 32 与树图初价 36，并核正根值。这些结果均按方程、确切算术及原书页面重新核对。


七组完整 C11/Python 程序：P/Q 线性求解、泊松计数、更新长度偏置、连续时间停留、停止随机游走、完整期权树、Black–Scholes 与 CRR。十四份源文件按六章保存在 [code 目录](../code/README.md)，网页中保留完整阅读副本并提供下载入口；样式、JS、图仍在 HTML 内。源书版本与逐题页码见 [source_manifest.json](source_manifest.json)。

在项目根目录运行：

    make -C code
    python3 tools/sync_code.py
    python3 tools/check_notes.py --extract-only
    python3 tools/check_notes.py

make 编译独立 C 程序，sync_code 检查源码与网页逐字一致。check_notes 的 --extract-only 模式检查结构、源文件下载和 PDF 链接并提取页面副本；完整模式还严格编译 C11、执行 Python、核对有理数/解析基准、语言一致性与 ASan/UBSan，验证固定种子记录。修改 code 下的程序后，先运行 python3 tools/sync_code.py --write 再检查。完整验证使用 Python 标准库、clang 和 Poppler 的 pdftotext。每次运行报告默认在 tmp/notes-check；可用 --run-dir 指定独立检查目录，本次证据保存在 tmp/audit-fix-check。

验收记录见 [validation.json](validation.json)。程序已通过七组程序、159 组独立数值基准、46 组非法输入、四项固定种子仿真及六个期数的 CRR 收敛检查，C11 严格编译、ASan/UBSan 与 C/Python 输出对照均通过。正文复核时增加 22 组示例数值基准，覆盖矩阵、退出、完整树与期限舍入。代码抽离后再次执行完整检查，并用 make 编译的七个独立 C 程序核对各章运行示例；十四份源文件与网页阅读副本逐字一致，本次另修正输入分词、行权舍入判断、累加顺序和输出格式。
