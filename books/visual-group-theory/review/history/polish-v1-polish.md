八个长题步骤/小问锚点在桌面与手机各检查一次，共 16 例；答案自动展开，目标实际未被顶部栏遮挡。第 2—4 章各在桌面/手机关闭 JavaScript 检查，共六例，原生注解可折叠和展开。手机证据是 Chromium 设备视口模拟，不含实体手机或真实屏幕阅读器朗读测试。可访问树抽查确认 Sylow 数公式为 MathMLMath，名称是原记号。

实际浏览器选取发现原生 MathML 纯文本序列化会把下标拆行，因此增加复制增强：完整公式或含公式段落复制为原记号，富文本保留 MathML。普通文本与局部公式不拦截；无 JS 时保留静态公式，纯文本格式由浏览器决定。六类 copy 事件 / DataTransfer 回归在真实页面运行，包括跨段换行和局部选取边界；不读取或写入系统剪贴板。可复用函数为 tools/check_math_copy.js。

过程中两次测试脚本判断需校正：深链初始用统一 100px 阈值，实际桌面栏高 57px、目标位于 96px，并未遮挡，改为实际元素命中测试；代码横滚初选了无需横滚的短输入块，读回尺寸后改选实际 C 源码块。失败输出保留，最终成功记录单列；没有改弱正文数学检查。初次题面哈希失败是预期检测到 MathML 标记变化，经题面还原比对后更新绑定。
