## P／Q 线性方程与多步转移

模式包括 pstation、qstation、psteps、ptime、qtime、pprob、qprob。输入先给状态数和逐行矩阵；psteps 再给步数、初始分布，time/prob 再给边界数组。边界的 −1 表示内部状态，退出时间边界为 0，退出概率边界取 [0,1]。矩阵条件、双精度主元阈值及完整算例见第一章计算实验。

Python：

```sh
python3 code/chapter01_markov_chains/linear.py pstation <<'EOF'
3
0.5 0.4 0.1
0.2 0.5 0.3
0.1 0.3 0.6
EOF
```

C：

```sh
./code/build/linear pstation <<'EOF'
3
0.5 0.4 0.1
0.2 0.5 0.3
0.1 0.3 0.6
EOF
```

[回到正文](../../notes/chapter01_markov_chains.html#pair-linear) · [C 源文件](linear.c) · [Python 源文件](linear.py)

消元先逐行缩放，再作部分主元消元；缩放后的主元绝对值小于 `1e-12` 时返回数值失败（退出码3）。这既包括奇异系统，也包括双精度下严重病态的系统，不能把退出当成数学上无解。整体缩小生成矩阵通常可被行缩放消除，但相差过大的跃迁速率仍可能被拒绝；这类模型应采用确切有理数或高精度求解。

P 的逐行概率和允许 `1e-8` 的输入舍入误差。平稳和边界方程用同一行的非对角概率之和表示离开概率，避免 `1-p_ii` 在 `p_ii` 接近一时损失有效数字。这等于按概率守恒补齐对角；`psteps` 则直接使用输入矩阵。若行和误差会影响长时间递推，应先提供归一化的矩阵。输入错误返回2，数值失败返回3，并输出诊断。
