# ADR-001 · 在现有仓库中组织书籍子项目

日期：2026-10-12。状态：采用。关联 [I001](../../issues/I001-project-merge.md)。

用户选择复用当前仓库，并要求将随机过程和 Weiss 的笔记统一管理。此前统一站点已经提供两书入口，但构建依赖另一个本机工作目录；内容、编译入口和维护约定还分散在两处。

采用 `books/<id>/` 保存独立书籍内容，根层负责书籍登记、治理、验证分派、书架与发布。每章继续是独立完整 HTML。保留两本书的代码维护源：随机过程独立源码同步到页面，Weiss 教学代码从 HTML 提取，原图例另由 `c/` 提供可执行版本。已有内部路径由注册表描述，新书可采用推荐结构。

该选择使一次克隆包含构建与验证所需的正式资料，保留章节离线阅读和源书核对，也减少同时维护算法副本的风险。目录统一不改变算法与教学格式，后续增加书籍需明确接入它的检查和发布转换。

兼容性：源码入口迁入 `books/`，根命令接替原散落命令；发布目录仍使用 `stochastic/`、`weiss/`，因此站点 URL 与旧入口兼容。Git 历史、远端及现有本地目录名继续沿用，GitHub 仓库改名不在本次范围中。

恢复方式：迁移前快照包含当前未提交改动；原 Weiss 目录保留。遇到问题逐文件对比和恢复，不重写历史，也不清除用户改动。具体来源、备份和验证见 [迁移记录](../migration-20261012.md)。
