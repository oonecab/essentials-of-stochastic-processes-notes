# ADR-003：退役宿主机历史 MySQL

日期：2026-10-17。状态：已接受。关联 [I030](../../issues/I030-host-mysql-removal.md)。

宿主机有一套至少自 2024 年存在的 MySQL，独立开机自启。现有站点由 Nginx 直接服务静态文件，核查没有发现应用数据库连接；唯一历史业务库包含两张表。该服务不属于 Reading Notes 技术栈。

项目所有者在了解历史数据和运行状态后，明确要求直接卸载、删除且不备份。本次按该授权清除数据库、服务专属配置和日志，停止并移除自启入口。包管理模拟发现 mysql-common 和 libmysqlclient21 被现有 mailutils 依赖，故保留这两个共享依赖，只清除五个服务端/命令行客户端包。

这一选择释放服务资源并关闭数据库监听。数据库历史内容删除后不能通过本次操作恢复；未来重新安装只能建立新实例。Nginx 配置、证书、静态发布版本和网站回滚材料保持，不将包管理器建议的其他自动依赖清理扩展为本次操作。
