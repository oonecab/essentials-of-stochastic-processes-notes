# ADR-004：退役 Weiss 独立站点

日期：2026-10-17。状态：已接受。关联 [I031](../../issues/I031-retire-weiss-site.md)。

Weiss 笔记已统一通过 Reading Notes 的 /weiss/ 路径发布。项目所有者已停用旧独立域名、删除 DNS，并要求清理服务器上的旧站点文件和 Nginx 配置。

清除旧站独占的发布目录、部署材料、日志、vhost 以及专属证书续期条目；保留主站当前版本和回滚材料、所有教材维护源、其他站点配置与证书。先退出有效 Nginx 配置并验证保留站点，再执行文件清理。

清理后旧独立部署副本不再作为恢复点；如将来重新启用独立域名，需要从维护源重新发布并配置 DNS/TLS。Reading Notes 主站版本与访问路径保持，旧证书仅在本机删除，不发起证书吊销。
