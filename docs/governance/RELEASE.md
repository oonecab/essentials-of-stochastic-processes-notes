# 发布治理

<!-- project-governance:managed:start -->
本文件记录发布准备、执行和结果；批准依据由变更控制记录负责，架构依据由 ADR 负责，不在此重复维护。

## 发布前

- 确认范围、版本、负责人、依赖、迁移顺序、兼容性影响和回滚路径。
- 确认代码、测试、权威规则文档、API 文档、数据文档和用户说明已按影响评估同步。
- 运行已登记的质量门禁并检查证据，不得用跳过、删除或弱化测试的方式获得通过结果。
- 核对秘密管理、环境变量、可观测性、容量、数据完整性和支持准备情况。
- 关联有效的变更控制与批准记录；生产操作必须在执行前取得明确授权。

## 发布中

- 记录实际命令或自动化任务、时间戳、版本、操作者和与计划的偏差。
- 按既定顺序执行，并在每个关键阶段验证健康状态与数据一致性。
- 出现回滚触发条件、证据不一致、安全边界冲突或无法界定的不确定性时立即停止，并按授权流程回滚或升级处理。

## 发布后

- 验证系统健康、关键用户路径、计算结果、数据完整性及外部系统对账。
- 记录实际生效版本和时间、监控结果、事件、后续问题单，以及完成或回滚证据。
