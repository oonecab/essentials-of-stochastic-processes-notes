范围：清理 Git 已忽略且可重建的编译/字节码产物、无运行进程的站点解包副本、旧的独立导出副本、过期笔记生成环境及确认与正式维护源逐字相同的提取件。正式 HTML、书籍 PDF/压缩来源、源码、规则与治理文档、验证摘要、历史日志/截图/输入、迁移基线和正在服务的预览保留。根 Git 历史、索引与既有用户修改保持。

变更控制：依据本次用户请求执行可恢复本地清理；精确清单在实施前冻结，移至废纸篓后逐文件核对。没有技术栈、计算规则、持久配置、服务或端口变更，相关 TECH、规则索引、治理配置及环境文档无需更新；README 补充上传与清理边界。没有生产发布、外部写入、提交或推送。

验收：保留集合字节不变；清单中的目标离开项目并能按原路径恢复；原预览仍返回同一内容；登记的项目检查与本地构建通过；Git 变化仅为本次工作记录及说明，旧修改不丢失。若发现新运行进程、目标变化或未明用途，停止对应目标的清理。

证据只写入忽略目录 tmp/cleanup/；恢复清单另保存在本次独立废纸篓目录。清理后的目录缩减不等于系统已释放磁盘空间。
