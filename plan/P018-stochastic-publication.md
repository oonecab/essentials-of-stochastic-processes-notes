# P018：随机过程修订发布计划

日期：2026-10-16。状态：in_progress。关联 [I018](../issues/I018-stochastic-publication.md)。

1. 核对当前差异、维护源和既有审阅绑定，确认 Git 远端与生产目标，登记恢复条件。
2. 导出实际暂存内容，完成秘密扫描、登记检查、统一构建及临时 HTTPS 验收；核对导出源与本地版本一致。
3. 提交并推送 `main`，读回本地、跟踪分支和远端提交；保存构建版本对应的源码树。
4. 在现有认证渠道可用后读取服务器基线，上传新版本，验证归档和解包内容，保存旧链接与配置，按既有流程原子切换。
5. 验证源站和公网全部发布文件、入口与 PDF 范围响应；在真实浏览器检查受影响章节、证明和习题入口、目录、资料与下载。
6. 记录实际生效版本、恢复点和验收结果，补充结果文档并推送，核对工作区与远端状态。

每一步以实际证据完成为准；服务器认证准备与本地提交、构建工作分别推进。
