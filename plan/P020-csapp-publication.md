# P020：CS:APP 修订发布计划

日期：2026-10-16。状态：in_progress。关联 [I020](../issues/I020-csapp-publication.md)。

1. 检查当前分支与远端、全部候选差异、审阅证据和文档联动；处理阻断问题，执行敏感信息扫描。
2. 运行三书登记检查、构建及临时 HTTPS 包验证；确认本轮浏览器验收对象与发布 HTML 相同。
3. 提交明确范围并推送 `main`，核对本地提交、跟踪引用和远端引用，保存源码身份。
4. 核对服务器、配置和恢复点；上传新版本，校验归档及解包文件，测试配置后原子切换并 reload。
5. 验证源站、公网逐文件响应、入口、PDF、桌面与 390px 实际阅读路径；保存旧版和配置供回滚。
6. 补齐发布结果，提交推送验收记录，核对最终远端及工作区。
