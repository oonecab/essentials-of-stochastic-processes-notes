# P030：宿主机 MySQL 卸载计划

关联 [I030](../issues/I030-host-mysql-removal.md)。

1. 读取当前服务、连接、包依赖和精确数据路径；保存包状态、文件系统容量、Nginx 配置哈希、站点 current 和响应基线。
2. 以模拟卸载确认只删除五个 MySQL 包，保留邮件工具依赖；用户已明确要求不备份。
3. 停止 MySQL、取消自启；清除五个包及数据库、专属配置与日志，核对残留目录再定向处理。
4. 验证包和服务不存在、无 mysqld 进程及数据库监听、目标数据消失；包管理器状态完整。
5. 对比 Nginx 配置和 current，复查源站及公网响应、实际释放空间；同步环境记录与验收结果。

上述步骤已完成，实际结果及访问边界见 [T030](../test/T030-host-mysql-removal.md)。
