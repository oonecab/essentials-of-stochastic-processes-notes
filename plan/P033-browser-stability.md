# P033：浏览器稳定性与上线计划

1. 保存原失败证据，先写可失败的节点竞态、报告保全、会话恢复和并发回归。
2. 等待与读取绑定预期文档；每次运行独立保存报告、日志和截图，只在完整成功后原子更新成功入口。仅明确失效的缓存空间自动恢复；显式空间选择及控制权错误立即失败。
3. 构建、parity、完整离线矩阵连续两轮、完整项目检查；核对静态包与既有候选的一致性。
4. 服务器验证访问、保留回滚，依 OPERATIONS-I032 迁移安装器权限并部署已验收版本；安全配置与证书逐项记录实机证据。
5. 同步权威文档和验收记录，秘密扫描、提交推送及远端读回。

回滚：浏览器脚本可回退 Git；每次验收历史输出保留。生产保留原 helper/unit/sudoers、属主模式清单及原 release，迁移未通过不切换 current。

执行结果：第 1–4 项中的本地修复、重复完整检查、权限迁移和站点上线已完成，证据见 [I033 报告](../docs/browser-stability-report.md)。自动续期按用户后续安排提供 DNS 配置交接，root 密码仍由用户自行轮换；Git 推送以交付时远端读回为准。
