# T001 · 子项目迁移测试设计

关联 [I001](../issues/I001-project-merge.md)。本设计验证目录和发布兼容性，并复用原有有独立参考的程序测试；不以迁移检查重新宣称全部数学结论已证明。

| 场景 | 方法 | 失败判据 |
|---|---|---|
| 子项目独立 | 注册目录、页数和入口检查；从主目录运行两书检查 | 缺文件、结构/题号/依赖不一致或引用越界 |
| 源码与正文 | 随机过程源码同步；Weiss 从正式 HTML 提取 | 代码副本不一致或提取/组合失败 |
| 数值与功能 | 原有 C11、ASan/UBSan、Python、独立基准、非法输入、TestKit 和图例检查 | 输出、退出码、不变量或内存检查失败 |
| 内部取源 | 旧构建器必须给外部参数；新构建器不带外部路径运行，在隔离副本中再次构建 | 依赖旧工作目录或源码清单缺项 |
| 源内容保持 | 与迁移前清单比对 22 个正式 HTML、算法源码、PDF 与原图例 | 非计划变更或源目录丢失 |
| 阅读界面保持 | 新旧统一包 HTML/CSS/脚本逐文件对比；代表路径宽屏与 390px 操作 | 发布字节改变未解释，导航/布局失效 |
| 发布文件 | 两次相同源构建的归档与站点哈希对比；安全解包拒绝越界和篡改成员 | 归档不一致、路径逃逸或校验未拦截 |
| HTTPS 兼容 | 隔离 Nginx 运行现有验证器，覆盖全部直接文件、六入口、查询参数、HEAD/POST、PDF Range | 任一状态、哈希、MIME、CSP 或范围内容不符 |
| 治理 | 生成器再预览、校验受管区块、检查命令与源目录存在 | drift、冲突、缺入口或缺命令 |
| 文档 | README/部署/规则/计划的真实文件链接检查 | 本机绝对路径或缺目标 |

运行入口是 `python3 tools/project.py check`、`build`、`verify-release`。扩展 Weiss 实验计数时使用 `check --book weiss --benchmarks`。新公共归档工具的错误输入用独立构造的损坏哈希和 `../` 成员验证，不复制实现来判断结果。

生成器对人工 README 与 `.gitignore` 的 PRESERVE 提示需人工审阅；它们不属于受管 drift。实际结果与日志位置在 [迁移记录](../docs/migration-20261012.md) 中登记。性能数据仍为原有实验环境记录，本次不重新测量性能表。
